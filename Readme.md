# AI-Powered Invoice Extraction and PDF Generator

This project uses AI to parse raw invoice text input, extracting customer and item details with quantity, price, and total calculations. It then dynamically generates an HTML invoice and converts it into a PDF using the PDFco API.

## Features

- Robust natural language invoice data extraction
- Automatic calculation of totals
- Dynamic, professional invoice HTML generation
- Integration with PDFco for PDF creation

## Setup & Usage

1. Configure AI agent with the provided prompt for parsing.
2. Use function nodes to convert extracted JSON to HTML.
3. Provide HTML to PDFco API node for PDF generation.
4. Retrieve or send generated invoice PDFs.

## Environment

- Ensure API credentials for PDFco are set correctly.
- Node.js or Python environment depending on backend.
